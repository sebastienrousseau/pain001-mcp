# Development

Use the native commands in Makefile and CONTRIBUTING.md. Coverage remains
100% line and branch. Test unreleased coordinated features against the matching
core branch. Never rewrite published history.

Edit docs/readme-values.json, then run `python scripts/render_readme.py`.
CI checks generated output; do not edit the canonical template layout.
