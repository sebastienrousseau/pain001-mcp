# pain001-mcp v0.0.78

## Highlights ⭐️

* **Faces tools**: `list_faces` names each face, its target and the binding keys it accepts; `project_face` takes a pain.001 document as XML text and returns a UK Open Banking v4.0.1, Berlin Group NextGenPSD2 v1.3.16 or ISO 20022 element-name payload, with a loss report of every source element not carried. The server registers 28 tools.
* **Refusals are data**: a missing required element, a binding the face does not accept, a file path instead of XML or an entity declaration comes back as `{"error": ...}`, never an exception.
* **In lockstep with pain001 0.0.78**: requires `pain001[fast]` and `pain001-loader-mt101` 0.0.78, the release that ships `project_face_text`.
