# pain001-mcp v0.0.85

## Highlights ⭐️

* **In lockstep with pain001 0.0.85**: the 30 tools and their results are the same as in 0.0.84. The core release this ships with adds `pain001 download` and `pain001 status` on the command line.
* **Questions go to GitHub issues**: the support, security and governance documents and the issue-template contact link point at this repository's issues; the pain001 suite does not use GitHub Discussions.

## Details

pyproject.toml, `__version__`, CITATION.cff, glama.json (with its Docker tag), server.json and the README move to 0.0.85 together, as `scripts/verify_versions.py` requires. The bug-report form now suggests the current version instead of 0.0.52.
