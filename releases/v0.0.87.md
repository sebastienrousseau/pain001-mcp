# pain001-mcp v0.0.87

## Highlights ⭐️

* **One verdict on every surface**: the validation and generation tools now run pain001 0.0.87's own validation, the checks the CLI and REST API run, so a payload the CLI refuses (for example `currency=EURO`) is refused here too, with the same `P001-E...` issue codes. A new test feeds the same files to the CLI, the REST API and the MCP tools and checks they agree.
* **Errors you can act on**: each `validate_records` error carries the row's `line` and the core's stable issue `code`, and a generator's refusal lists its `issues` with line, column, code and message.
* **Every core input format from a file**: `generate_message_from_file` reads CSV, SQLite, JSON, JSONL and Parquet through the CLI's own loader, as `list_supported_formats` already said.
* **A safer Suite Consistency check**: it no longer runs on another workflow's completion, so it never runs with the default branch's trust on behalf of an untrusted trigger.

## Details

Requires pain001 0.0.87. pyproject.toml, `__version__`, CITATION.cff, glama.json (with its Docker tag), server.json, the bug-report form and the README move to 0.0.87 together, as `scripts/verify_versions.py` requires.
