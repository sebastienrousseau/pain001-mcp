# pain001-mcp v0.0.88

## Highlights ⭐️

* **Tool descriptions that stay in their lane**: `list_corpus_files` and `list_message_types` no longer tell the agent to call or avoid other tools, so each description governs only its own tool. `passmcp check --stdio` scores the server 98.125 out of 100, up from 90.625 on 0.0.87.
* **opentelemetry-api 1.45.2 or newer**: the floor moves up in the manifest and every hash-pinned lockfile, clearing CVE-2026-126360.
* **In lockstep with pain001 0.0.88**, the family's first release with the five SDKs: requires pain001 0.0.88 and pain001-loader-mt101 0.0.88, and the Suite Consistency check now audits all fourteen repositories.

## Details

pyproject.toml, `__version__`, CITATION.cff, glama.json (with its Docker tag), server.json, the bug-report form and the README move to 0.0.88 together, as `scripts/verify_versions.py` requires.
