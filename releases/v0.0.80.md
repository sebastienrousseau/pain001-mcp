# pain001-mcp v0.0.80

## Highlights ⭐️

* **Committed files stay in the output directory (GHSA-hqw7-q8v2-pq3m)**: `commit_payment_batch` used to write to any path it was given, creating directories and replacing files. It now writes only new `.xml` files inside `PAIN001_MCP_OUTPUT_DIR` (else the server's working directory) and refuses anything else. Affects 0.0.72 to 0.0.79.
* **No more dual-control claim**: the confirmation token comes back to whoever staged the batch, so the tools now describe it as protection against an accidental commit.
* **In lockstep with pain001 0.0.80**, the security release of the whole suite.

## Details

Upgrade every deployment, and especially any that exposes the HTTP or SSE
transport. Pass `output_file_path` relative to the output directory, or
set `PAIN001_MCP_OUTPUT_DIR` to the directory committed files belong in.
