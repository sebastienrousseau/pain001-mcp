# pain001-mcp v0.0.91

## Highlights ⭐️

* **Safer `commit_payment_batch` writes**: an output path with a NUL byte, a trailing slash or `.` is refused before anything is created, committed files are owner-only, a failed write leaves no partial file, and error messages no longer reveal the server's output directory. Confinement to the output directory held on 0.0.90; this closes the edge cases reported privately by Serhii Shunko.
* **In lockstep with pain001 0.0.91**: requires pain001 0.0.91 and pain001-loader-mt101 0.0.91. The 30 tools otherwise behave as they did in 0.0.90.
* **Dependabot updates folded in**: ruff 0.17.6, fastapi 0.165.0, filelock, virtualenv and soupsieve in the hash-pinned sets, and the CodeQL, Scorecard and check-ecosystem action pins (#178 to #183). No runtime dependency changes beyond the two suite packages.

## Details

pyproject.toml, `__version__`, CITATION.cff, glama.json (with its Docker tag), server.json, the bug-report form and the README move to 0.0.91 together, as `scripts/verify_versions.py` requires.
