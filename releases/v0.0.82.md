# pain001-mcp v0.0.82

## Highlights ⭐️

* **`check_payment_file`**: checks a pain.001 or pain.008 file you already have, sent as XML text, with the core's `check_document`: the XSD of the message type its namespace names, the message definition's cross-element rules, and the scheme profiles and Schematron preset you ask for, every finding at once. A Schematron rulebook is named by preset, never by path. 30 tools.
* **A facts file on every release**: `pain001-mcp-<version>.facts.json` lists the version, the Python and pain001 floors, and the tools, resource templates and prompts an MCP client sees, with their counts.
* **In lockstep with pain001 0.0.82**: requires pain001 and pain001-loader-mt101 0.0.82. Through the core, the generate tools now write a valid IBAN as `<IBAN>` and a non-empty `service_level_code` as `PmtTpInf/SvcLvl/Cd` in pain.001.001.04 to .08.

## Details

Tool names and result shapes are unchanged apart from the new tool.
Rows whose `service_level_code` values differ are now refused for
pain.001.001.04 to .08, as the core refuses them. anyio, dulwich,
filelock, ruff and virtualenv moved to their latest releases.
