# pain001-mcp v0.0.81

## Highlights ⭐️

* **Inline rows get the CLI's answer**: `validate_records` and the generate tools now check every IBAN (mod-97) and BIC column and refuse rows that cannot share one payment batch, naming the column but never the value. Before, an IBAN with a broken check digit validated and generated here while the CLI refused it. `identifier_checks=false` opts out, like `--no-identifier-checks`.
* **`list_scheme_profiles`**: lists every scheme profile the installed core ships, with its description, rule-id prefix and sources, and the scheme parameters carry the profile names as a JSON Schema `enum`. 29 tools.
* **In lockstep with pain001 0.0.81**: requires pain001 and pain001-loader-mt101 0.0.81. Message-type names now come from the core, and `server.py` is split by tool family with every function inside the complexity ceilings.

## Details

A batch that mixes debtors, execution dates or charge bearers is now
refused by `validate_records`, the generate tools and the staging
tools, as pain001 0.0.81 refuses it. Tool names and result shapes are
unchanged.
