# pain001-mcp v0.0.90

## Highlights ⭐️

* **In lockstep with pain001 0.0.90**: requires pain001 0.0.90, the core release that fixes the `lazy_module` import race which gave a freshly started server's first parallel requests an HTTP 500. The 30 tools behave as they did in 0.0.89.
* **Requires pain001-loader-mt101 0.0.90**: the MT101 loader moves with the suite; nothing in its parsing changed.
* **Container on Python 3.15**: the Docker image's base moves from `python:3.14-slim` to `python:3.15-slim`, folded from Dependabot #176. The package itself still supports and is tested on Python 3.11 to 3.14.

## Details

pyproject.toml, `__version__`, CITATION.cff, glama.json (with its Docker tag), server.json, the bug-report form and the README move to 0.0.90 together, as `scripts/verify_versions.py` requires.
