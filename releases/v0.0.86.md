# pain001-mcp v0.0.86

## Highlights ⭐️

* **In lockstep with pain001 0.0.86**: the 30 tools and their results are the same as in 0.0.85. This release tightens the checks around them and completes the repository's documentation.
* **Every example and the Quick Start run in CI**: examples 04 and 05 were never executed there, and the README Quick Start commands now run as tests, so a broken example or renamed flag fails before a reader copies it.
* **The manual is checked on every pull request**: it builds with warnings as errors and is link-checked on each pull request and release-branch push, and now includes `ARCHITECTURE.md` and the `check_payment_file` tool's API reference.
* **Accurate security and contribution guidance**: `SECURITY.md` states that the HTTP transports open an unauthenticated loopback listener, and gains the supported-versions policy and private vulnerability reporting; `CONTRIBUTING.md` states the dual licence and signs off its example commit.

## Details

pyproject.toml, `__version__`, CITATION.cff, glama.json (with its Docker tag), server.json, the bug-report form and the README move to 0.0.86 together, as `scripts/verify_versions.py` requires.
